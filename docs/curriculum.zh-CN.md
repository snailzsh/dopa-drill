# 中文技能目录

共 58 项计算技能。年级、前置关系与题目范围沿用上游版本，不代表中国大陆教材顺序。这里只覆盖计算训练，不包含完整的图形、测量、图表或应用题课程。

具体生成参数见 `app/js/skills.js`，原始范围说明见 [上游课程文档](curriculum.md)。
