# Dopa Drill · 非官方简体中文版

这是 [grmchn/dopa-drill](https://github.com/grmchn/dopa-drill) 的非商业中文修改版，由 `snailzsh` 维护。原作者为 **gear_machine**。本版本与原作者无官方关联，保留原 Logo、角色、音乐和动画。

每完成一道算术题，角色动画、音效和音乐就会更热闹。答错后可以继续，没有游戏结束惩罚。整个应用在浏览器运行，不需要账号、后端或大模型 API。

## 中文版内容

- 简体中文界面、按钮、设置、无障碍标签和新手教程。
- 58 项技能的中文名称、题目标题、分步提示、余数与带分数表达。
- 中文任务、306 个奖杯、47 件收藏品、星级条件、成长记录和时光胶囊。
- 中文星期、数字单位和字体回退；原 Logo 中的日文字样按原样保留。
- 原有出题范围、评分、解锁规则和存档结构保留。

**年级划分沿用原版，不代表已经适配中国大陆教材。** 这里的“中文版”指语言与显示本地化。当前交付物是网页应用，尚未移植为微信小程序。

## 本地运行

需要 Python 3。无需安装前端依赖或构建。

```bash
git clone https://github.com/snailzsh/dopa-drill.git
cd dopa-drill
python3 -m http.server 8000 --bind 127.0.0.1 --directory app
```

在浏览器打开 <http://127.0.0.1:8000/>。不要直接双击 `app/index.html`：应用使用 ES Modules，需要 HTTP 服务。

手机或电脑均可操作；电脑支持数字键和 Backspace。首次打开会显示中文教程。设置中可调整题数、音量和动画强度，也可以观看自动演示。

正式网页托管时，只需发布 `app/` 目录。本仓库没有自动开通或发布在线站点。

## 学习记录

记录保存在当前浏览器的 `localStorage` 中，不上传服务器。更换设备、浏览器或网站地址不会自动同步。清除网站数据或使用“重置全部数据”会清除记录。

本版本使用原版存档键。现有存档中已保存的历史题目可能仍带有原文；新生成的题目使用中文。

## 验证

需要 Node.js 20 或更高版本：

```bash
node --test tests/*.test.mjs
```

测试包含题目数值与排版、评分、技能解锁、任务、奖杯、存档，以及中文文案检查。中文检查覆盖全部技能生成器，并允许原 Logo 保留日文。测试不等于 iOS、Android 全机型验收。
